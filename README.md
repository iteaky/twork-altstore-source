# TWORK — CRM for personal trainers on iPhone (early access)

**[TWORK](https://iteaky.github.io/twork-altstore-source/)** is an iPhone-first, local-first CRM for personal trainers, online coaches and trainers working with fitness clubs. It brings client records, training schedules, subscriptions, package balances, payment bookkeeping and optional Apple Calendar sharing into one workflow.

**Product descriptions:** [English](https://iteaky.github.io/twork-altstore-source/en/) · [Русский](https://iteaky.github.io/twork-altstore-source/) · [Slovenčina](https://iteaky.github.io/twork-altstore-source/sk/)

## What TWORK does

- [Client management](https://iteaky.github.io/twork-altstore-source/features/personal-trainer-crm/): client records, appointments and notes
- [Training schedules](https://iteaky.github.io/twork-altstore-source/features/training-schedule/): sessions, rescheduling and time zones
- [Subscriptions and payments](https://iteaky.github.io/twork-altstore-source/features/subscriptions-and-payments/): packages, balances and payment records
- [Client Apple Calendar sharing](https://iteaky.github.io/twork-altstore-source/features/apple-calendar/): optional individual calendars
- [Fitness club settlements](https://iteaky.github.io/twork-altstore-source/features/club-finances/): separate private and club finances
- [Online coaching in different time zones](https://iteaky.github.io/twork-altstore-source/features/online-training-timezones/)

## AltStore Classic beta source for testers

This public repository also hosts the AltStore Classic beta source. The actual iOS application code is in a separate private repository.

1. Install AltStore Classic with AltServer.
2. Open AltStore on iPhone → Sources.
3. Add `https://iteaky.github.io/twork-altstore-source/source.json`.
4. Install the available TWORK beta if offered.
5. Refresh via AltStore per your signing arrangement (typically every 7 days).

The AltStore beta and TestFlight early-access channels are separate; their release versions and availability may differ.
